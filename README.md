# 通话已接通：社牛/社死挑战

一个微信H5风格的小游戏原型，模拟在公共场合接到"不该接"的电话时的快速决策挑战。

## 快速开始

直接用浏览器打开 `index.html` 即可试玩。无需服务器，无需 npm。

## 玩法

- 每局 30 秒
- 系统随机显示场景（如地铁、电影院）和来电人（老板、对象、老妈等）
- 3秒内从3个选项中快速选择应对策略
- 系统根据场景+来电人+选择的组合计算"社死值"与"装得像分"
- 连续正确选择获得连击加成；社死值过高会触发暴击
- 目标：在30秒内获得尽可能高的总分

## 技术

纯静态 HTML + CSS + JavaScript，无依赖，单文件。
